# Fast Food Tracker (Expo React Native)

High-performance food tracking MVP with onboarding, macro + micronutrient tracking, diet templates, zigzag calories, daily logs, supplements, and water tracking.

## Run

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start Expo:
   ```bash
   npx expo start
   ```
3. Open on phone:
   - Install **Expo Go** on iOS/Android.
   - Scan the QR code from terminal.
